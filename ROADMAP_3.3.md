# Pistes pour Auto Chest Opener 3.3

La 3.3 ne devrait commencer qu'après tests réels de la 3.2 sur plusieurs conteneurs 12.1.

Priorités proposées :

1. corriger en premier les cas réels où la confirmation, les locks ou les protections du client se comportent différemment ;
2. ajouter un export de diagnostic compact partageable (version, mode, profil, file, circuit, dernières erreurs) ;
3. ajouter une action explicite de réarmement d'un circuit depuis l'éditeur de règles si le besoin apparaît en jeu ;
4. envisager une vue de gestion en masse des règles si le nombre de conteneurs suivis devient important ;
5. n'ajouter le CSV d'historique que si les données sont réellement utilisées hors jeu.

À éviter : multiplier les fenêtres flottantes ou accélérer la file au prix de la confirmation stricte.
